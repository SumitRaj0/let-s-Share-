# LetsShare — Beat ShareCode Plan

Goal: match ShareCode’s collaboration baseline, then win on **share + run + control**.

## Status: Phases 1–4 COMPLETE ✅

## Product principles
1. Guest-first: create → share in under 10 seconds.
2. One link = view / edit / run (by permission).
3. Durable storage — shares survive restarts.
4. Roles over chaos: Owner / Editor / Viewer.
5. Better than ShareCode where it matters: execute, expire/revoke, AI-for-sharing.
